# Summary

This repository is a representation of a practicum that my team did for Lufthansa, detailing how to analyze viral tourism destinations when given a previous year's flight data. 

For this project, I scraped data from TikTok and Youtube using a combination of Selenium and Youtube's API. I also assembled an XGBoost-based model to determine whether a given nation would be viewed as a viral tourist destination within a certain window of time. Further details are presented in the pdf file titled "Lufthansa Practicum Project Paper." 

Please note that this project was performed under NDA. As such, country names in the paper have been redacted in accordance with the agreement, and any code for data analysis would be completely unusable, as I cannot provide any information about the flight data provided to me. I have provided the code for scraping Youtube and TikTok as sample code, as that had nothing to do with the provided flight data.
