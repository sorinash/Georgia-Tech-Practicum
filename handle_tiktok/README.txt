
As a reminder: For TikTok scraping, be aware that using this script without any protections will likely get you blocked from accessing the site for a couple of days. I would recommend using the Brave browser (https://brave.com/) to avoid browser fingerprinting, along with a trustworthy VPN (I used Mullvad, available at https://mullvad.net/) to avoid IP detection. If you're using a different browser, you'll need to change the webdriver that's being used. Additionally, if you're only doing a brief scrape to test the script, the Brave browser should be sufficient, as TikTok's blocking seemed to be on a device-level basis rather than an IP basis (ie, my phone could still access TikTok from my network while my computer could not). 

You may need to change what version of Chromedriver that's being used, depending on your version of Brave. Additionally, you may need to change what path is being used; those are both in the same cell underneath a heading that says "If you're using a VPN, make sure to activate it before you run this next cell." 

At that point, just run all of the provided cells. Be sure to run the top cell after installing the requirements.txt, otherwise the rest of the cells won't run. Feel free to change placename_list to whatever you want from the provided lists, depending on how much scraping you want to do. If you want to scrape more than just a single tag per country (which I would recommend if and only if you're trying to scrape a meaningful amount of data, since there aren't many videos per hashtag on TikTok but also the video data is already in my other files), you can change the keyword and reverse variables. By default, it will search "#travel{country}", but if you wanted, you could search "discover{country}" by changing keyword to "country", or "{country}travel" by changing reversed to True. 

At the end, the final cell will consolidate all of the files for each country into a single file.
